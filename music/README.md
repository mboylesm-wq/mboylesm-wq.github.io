# PnoyChess Shared Original Music Library

Single source of original, 100% code-synthesized chess music for **PnoyChess Docu Studio** and **PnoyChess Reel Studio**.

- **Cost:** $0 (no ElevenLabs credits, no royalties, no subscription fees).
- **Mastering:** Stereo, 44.1kHz / 48kHz, EBU R128 loudness normalization (-16 LUFS), seamless reverb decay tails.
- **Access:** Direct CORS-enabled static hosting via GitHub Pages CDN.
