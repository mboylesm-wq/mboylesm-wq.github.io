Privacy policy

For the PnoyChess Poster tool and the PnoyChess channels. Effective 25 October 2026.

Who we are

PnoyChess is a chess content channel run by one person in the Philippines. PnoyChess Poster is its private publishing tool, used only for the PnoyChess accounts.

What the tool accesses

  • YouTube (YouTube API Services): the PnoyChess channel's own videos, their titles, descriptions, captions, thumbnails and playlists, and the channel's own analytics. Used to upload and manage PnoyChess's own videos.
  • Facebook and Instagram (Meta Graph API): the PnoyChess Page and its linked Instagram account, to publish PnoyChess's own reels and read their statistics.
  • TikTok: the PnoyChess account, to publish PnoyChess's own videos.

The tool does not collect, store or process personal data about viewers or any other person. It does not read comments, messages or subscriber lists.

How data is stored

Access tokens are stored only in a secure secret store used by the publishing system and are never shared, published or sold. Video files, captions and statistics about PnoyChess's own videos are kept in PnoyChess's private storage.

Sharing

No data is sold or shared with third parties. Data goes only to the platform it belongs to (for example, a video uploaded to YouTube goes to YouTube).

Google and YouTube

PnoyChess Poster uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time from the Google security settings page.

Storing and deleting YouTube data

  • The tool stores only the PnoyChess channel's own video IDs, titles and statistics (views, watch time, subscribers). It stores no data about viewers or other channels.
  • YouTube API data that is kept is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies. Channel statistics used for the owner's own reports are kept no longer than allowed by those policies.
  • Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked, or on request, all stored YouTube API data and tokens are deleted within 7 days.

Deleting other data

Revoking access in Meta or TikTok settings stops the tool immediately. Stored tokens are deleted within 7 days of a request or of revoking access.

Contact

Questions: send a message to the PnoyChess Facebook Page.
